# wujud من جوه: كل جزء بيعمل إيه

ده دليل للي عايز يفهم المشروع من غير ما يقرا الكود سطر سطر. الكود نفسه مكتوب بأسامي واضحة ومن غير كومنتات كتير، والشرح التفصيلي لكل جزء موجود في الـ README بتاعه.

## الصورة الكبيرة

```
 موبايل / لابتوب ──ping──► ESP32 (research/firmware/wujud_room)
        ▲                   │ بيقيس الـ CSI من ردودهم
        └────── رد ─────────┘ ويبعته سطر لكل packet
                            │ واي فاي (UDP) أو USB
                            ▼
                 الكمبيوتر (crates/app)
     udp/serial ─► proto ─► model ─► نافذة 3D (egui)
                  (يفك)    (يفهم)    (يعرض)
                    ▲
       crates/sim ──┘  (نفس السطور بالظبط، بس من محاكاة)
```

1. **البوردة** بتعمل شبكة واي فاي اسمها `wujud`. أي موبايل أو لابتوب يتصل بيها **بيبقى link**.
2. البوردة بتعمل ping لكل جهاز 100 مرة في الثانية، **وكل رد بيوصلها بيطلع منه CSI**: 64 رقم مركّب، كل رقم بيقول قوة الإشارة وزاويتها على تردد معيّن.
3. **البوردة بتاخد بس الـ packets النضيفة:** 802.11n من غير STBC. كروت اللابتوب اللي فيها أنتينتين بتبعت STBC، وده بيخلي الـ CSI يتنطط 4.5 dB بين كل packet واللي بعدها، فبيبان كأنه حركة وهي مش حركة.
4. البوردة بتبعت كل packet كـ**سطر نص**، على الواي فاي لأي حد طلب، أو على الـ USB.
5. **الكمبيوتر** بيفك السطور، ويحسب منها features، ويدخّلها للموديل. الموديل بيقول: الأوضة فاضية؟ فيه حد ساكت؟ فيه حد بيتحرك؟
6. **المحاكي** بيطلّع نفس الداتا اللي البوردة كانت هتطلّعها، بس من فيزيا. وده اللي دربنا عليه الموديل.

## كل جزء بالتفصيل

### `crates/proto`: لغة الكلام بين البوردة والكمبيوتر
- `P,<rssi>,<وقت>,<256 حرف hex>`: packet واحد من الـ CSI. البوردة بتسبقه باسم الجهاز: `<mac>|P,...`.
- `R,<مستقبل>,<مرسل>,<عدد>,<13 متوسط>,<13 انحراف>`: ملخص ثانية واحدة للينك واحد. ده في وضع المدرج.
- `I,...`: رسايل حالة: البوردة اشتغلت، جهاز اتصل، جهاز فصل.

الـ crate ده بيستخدمه الفيرموير والكمبيوتر الاتنين، فمستحيل الطرفين يختلفوا على الشكل.

### `crates/sim`: المحاكي
بيبني أوضة أو مدرج عشوائي، وبيحط فيه ناس بيعملوا حاجات (نايمين، قاعدين، ماشيين)، وبيحسب الإشارة اللي هتوصل للبوردة:
- **الخط المباشر** والانعكاسات على الحيطان والأرض والسقف (image method).
- **الجسم بيحجب الإشارة** (حيود Fresnel-Kirchhoff)، و**الصدر بيعكسها** وبيتحرك مع التنفس.
- **عيوب الـ ESP32:** الضوضاء، والـ AGC، والتقريب لـ int8، والـ packets اللي بتضيع.

### `research/rt`: محاكاة فيزيائية كاملة
- بدل المعادلات المبسطة، بيتتبع **كل شعاع** على الـ GPU بـ Sionna RT من NVIDIA.
- كل سطح ليه خصائصه الكهربية من معيار ITU، والإنسان بمفاصل وصدر بيتنفس.
- عيوب الـ ESP32 فيه متظبطة على تسجيلات البوردة الحقيقية.
- التفاصيل في `research/rt/README.md`.

### `crates/model`: الفهم
- **features:** من الـ CSI بنحسب مقاييس، زي قوة التغيّر في نطاق التنفس (0.12–0.6 Hz)، وفي نطاق الحركة، والبصمة الثابتة للأوضة.
- **الموديل:** gradient-boosted trees اتدربت على المحاكاة. نسخة الـ Rust بتطلّع نفس الاحتمالات اللي sklearn بيطلّعها بالظبط.
- **occupancy latch:** عشان نعرف إن فيه حد ساكت، بنقارن الأوضة دلوقتي بشكلها وهي فاضية من كام دقيقة. والحركة هي اللي بتقول إن حد دخل أو خرج.
- **motion tracker:** كل link بيقول قد إيه هو متلخبط دلوقتي. والـ CSI بيقول **فيه حركة ولا لأ**، والـ RSSI بيقول **الحركة قريبة من أنهي link**.

### `crates/app`: البرنامج
```bash
cargo run --release -p wujud -- live --ports udp:192.168.4.1 --room research/rec/room.json
cargo run --release -p wujud -- demo --boards 3
cargo run --release -p wujud -- demo-hall
cargo run --release -p wujud -- monitor --ports udp:192.168.4.1
```
- **`live`:** البوردة الحقيقية. كل جهاز متصل بيها بيظهر كـ link لوحده.
- **`demo` و`demo-hall`:** المحاكي بيلعب أوضة أو مدرج، والشبح الرمادي هو مكان الإنسان الحقيقي.
- **`monitor`:** الرسايل الخام.
- **`--record`:** بيسجل كل حاجة في ملف.
- **`examples/replay.rs`:** بيشغّل التسجيل ده تاني ويطبع النظام كان هيقول إيه كل كام ثانية، عشان تقارنه باللي حصل فعلًا.

### `research/firmware`: البوردة
```bash
research/firmware/board.sh flash
research/firmware/board.sh status
research/firmware/board.sh set ping_hz=200
```
- **`flash`:** بيحدّث الفيرموير على الـ USB، أو على الواي فاي لو البوردة بعيدة.
- **`status`:** كل جهاز بيبعت كام packet نضيف، وكام اترفض.
- **`set`:** بيغيّر الإعدادات، وبتفضل محفوظة بعد الـ reboot.

## إزاي نعرف إن الـ Rust صح؟
كل جزء اتنقل من الـ Python ليه اختبارات بتقارنه بالـ Python **على نفس الداتا**. الـ Python بيطلّع "إجابات نموذجية" (golden) في `crates/*/tests/golden/`، واختبارات الـ Rust بتتأكد إنها بتطلّع نفس الإجابات:
```bash
cargo test --workspace
```
